# CCPS 內容規則

- 唯一品牌 CTA：`追蹤ccps家慶佳業`。
- 文章不要求使用者提供證據或來源日期，可直接生成。
- 只有使用者按下「生成文章」才允許以目前分頁內的 API Key 呼叫一次 GPT；不得背景呼叫、自動重試付費步驟或把 Key 持久化。
- 每次最多明確選用一筆素材；含內部資訊、個資、僅供內部研究或待主管確認的素材不得傳送到雲端。
- 文章角色、開場方式、敘事結構、品牌人設與寫作指紋必須進入生成提示詞，不能只作為 metadata。
- 即時性主題顯示複核提醒，但不阻擋文章生成。
- 不得杜撰客戶、成交、會議、對話、日期或數據；偵測到假故事模式仍會阻擋。
- 專業文章必須有 CCPS 觀點與至少一組 trade-off。
- 最近內容以 Content DNA、3-gram Jaccard 與結構相似度檢查。
- 本機不自動執行付費 API、發布、Push 或 Deploy。
